# Battle Cats Save Editor

This Pterodactyl egg runs Battle Cats Save File Editor (BCSFE), originally
created by **fieryhenry**.

Original project and source code:
[fieryhenry / BCSFE-Python](https://codeberg.org/fieryhenry/BCSFE-Python).

Credit for BCSFE goes to fieryhenry and the project's other contributors.
This repository provides a Pterodactyl egg for the application.
